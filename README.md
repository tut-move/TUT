# TUT MVP v4

**TUT — Turn Unused Into Transport**

Visitor-ready validation build for a multi-sided capacity marketplace connecting Drivers, Trucks, Loads and Warehouses.

## Run

```bash
node server.js
```

Open `http://localhost:3000`.

## Included
- Visitor-facing black/gold TUT landing page
- Account registration and login
- Shared listings database
- Driver, truck, load, warehouse and storage-need listings
- Direct and combined matching (`Load + Truck + Driver`)
- Demo market seed

## Important
This is a validation MVP, not a production transportation system. Real transactions require production hosting, persistent sessions/database, identity verification, carrier/driver compliance, insurance, payments, security, monitoring and jurisdiction-specific legal review.
